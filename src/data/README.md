# Code tables

Generated by `npm run build-codes` (`scripts/build-codes.ts`). Don't edit by hand;
add fixes to `OVERRIDES` in the script and regenerate.

| File | Contents | Source | Licence |
|---|---|---|---|
| `airports.json` | IATA → [ICAO, IANA time zone] | [mwgg/Airports](https://github.com/mwgg/Airports) | MIT, © 2014 mwgg |
| `airlines.json` | ICAO designator → IATA airline code | [OpenFlights airlines.dat](https://openflights.org/data) plus overrides | [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) |

OpenFlights is no longer actively maintained, so newer airlines are added via the
script's overrides. Cargo airlines are left out on purpose: freighters aren't open
to staff travel and would otherwise create false routes.
